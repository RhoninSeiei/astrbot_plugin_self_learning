# 内嵌页面与群聊学习上下文适配

基于自用 `dev/lightrag-scheduled-ingestion` 分支 `ae8555b`，保留其定时知识摄取、持久化去重、队列恢复、群工作区隔离、学习任务取消和 JSON 分析修复。本次不另建知识摄取入口，也不回填历史。
